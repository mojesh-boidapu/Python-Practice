# Python Practice

This repository contains Python programs I created while learning and
practising Python. The programs cover basic concepts, conditional
statements, loops, functions, data structures, validation, and simple
problem-solving exercises.

The files are arranged in a beginner-to-advanced order to make it easier
to follow my learning progress. Each program focuses on a particular
concept and provides hands-on practice with writing and understanding
Python code.

## How to Run
**Option 1**: Run Online (No Installation Required)
You can run these programs in your browser using an online Python
compiler:
- Programiz Online Python Compiler
  -- A simple option for writing and running Python code.
- OnlineGDB Python Compiler
  -- Run Python code and provide input through its input panel.
- Replit
  -- An online coding workspace for running and saving Python projects.
Steps:
1. Open one of the online Python compiler websites.
2. Open the .py file you want to run from this repository.
3. Copy the complete code from the file.
4. Paste it into the website's code editor.
5. Click Run and provide input when the program asks for it.

Note: These websites run pasted code; they do not automatically run
a Python file just because it is stored on GitHub. Some programs may
behave differently if an online compiler has limitations on interactive
input or supported features.

**Option 2**: Run on Your Computer
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the repository folder in a terminal or code editor.
4. Run a program using:
   python filename.py

Replace filename.py with the name of the program you want to run.
